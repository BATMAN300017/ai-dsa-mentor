# Local Inference Runtime Directory (llama.cpp)

This directory reserves the workspace layout for local `llama.cpp` runtime configuration and future Task 2+ integration.

- No runtime binaries are bundled in Task 1.
- Runtime binaries must never be committed to Git.
- In packaged desktop distributions, downloaded/extracted runtime artifacts should reside under the OS application-data directory (`%LOCALAPPDATA%\AI DSA Mentor\runtimes\llama.cpp` on Windows, `~/Library/Application Support/AI DSA Mentor/runtimes/llama.cpp` on macOS, `~/.local/share/ai-dsa-mentor/runtimes/llama.cpp` on Linux).
